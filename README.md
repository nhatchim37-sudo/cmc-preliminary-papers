# CMC 全国大学生数学竞赛 · 初赛真题库

中国数学会主办 **全国大学生数学竞赛（China Collegiate Mathematics Contest, CMC）** 初赛（预赛）历年原卷归档，试卷版权归中国数学会及全国大学生数学竞赛组委会所有，本仓库仅作学习与备赛交流使用。

在线浏览：<https://nhatchim37-sudo.github.io/cmc-preliminary-papers/>
