# CMC 全国大学生数学竞赛 · 初赛与决赛真题库

全国大学生数学竞赛（China Collegiate Mathematics Contest, CMC）公开试题与参考答案归档。本仓库是个人整理的学习资料索引，非赛事官方网站，不代表所有版本均获官方认证。

- 在线浏览：<https://nhatchim37-sudo.github.io/cmc-preliminary-papers/>
- 直接进入决赛：<https://nhatchim37-sudo.github.io/cmc-preliminary-papers/?stage=final>
- 决赛逐文件来源、页数、文件大小与 SHA-256：[finals/catalog.json](finals/catalog.json)

## 页面使用

- 可按初赛／决赛、数学类／非数学类、细分组别、届次组合筛选。
- 筛选条件保存在页面网址中，可直接分享；从PDF返回后能按网址恢复筛选。
- 点击试卷主体在当前页打开PDF，或点击“下载 PDF”离线查看。下载行为由浏览器决定。
- 决赛卡片附来源链接；没有JavaScript时，全部资料仍可直接访问。
- 初赛合并版仍为第10–17届、270页，不含新增决赛。
- 如果内嵌预览无法导航，在系统浏览器打开网站网址；无需本地启动脚本访问GitHub Pages。

决赛采用ASCII文件路径。`questions` 为来源标注的试题文件，`solutions` 为独立参考答案，`combined` 为来源已有的试题与解答同文件版本。目录名和文件名不是官方认证标记。

## 数据来源与核验

决赛来源分布：

- **高校公开附件35份**：华东师范大学数学科学学院资料页，如[第1届资料页](https://math.ecnu.edu.cn/llin/20091024.HTM)、[第8届资料页](https://math.ecnu.edu.cn/llin/20161022.HTM)。
- **竞赛网站附件13份**：[大学生数学竞赛网](https://www.cmathc.org.cn/stxz_3/)及旧站 `cmathc.cn` 公开附件。
- **社区归档23份**：[IceFerryLing/Math_competition](https://github.com/IceFerryLing/Math_competition)。来源清单固定到归档提交，便于追溯。社区转载与参考解答不等同官方认证版本。

既有初赛资料来自大学生数学竞赛网公开下载及汇总栏目：<https://www.cmathc.org.cn/csst/>、<https://www.cmathc.org.cn/stxz_1>。

新增决赛文件检查了PDF格式、页数与可读取性，并抽查题头及部分解答页。每个文件保存SHA-256，社区下载同时核对Git blob校验值。这些检查不等于逐题校勘，不对全部解答的数学正确性作保证。

逐文件的原始标题、来源页、下载地址、页数、大小和SHA-256见 [finals/catalog.json](finals/catalog.json)。
